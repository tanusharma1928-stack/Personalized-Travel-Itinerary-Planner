# Personalized Travel Itinerary Planner (Skill Wallet Capstone Project 4)

Run locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy on Streamlit Community Cloud:
1. Push app.py, requirements.txt, README.md to a GitHub repo.
2. Go to share.streamlit.io, New app, pick the repo, main file = app.py, Deploy.
3. (Optional) Add LLM_API_KEY under App settings > Secrets / env, or paste a Gemini/Groq key in the sidebar.

Demo mode works without any API key.
